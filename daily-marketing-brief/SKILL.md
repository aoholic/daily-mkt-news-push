# 每日营销简报

## 目的

为中国大陆广告 / 市场营销从业者生成一份**可存档、可回溯、去重过的**每日行业资讯简报：一份完整的 `.md` 存档文件 + 一段可直接转发的精简推送文本。

## 适用场景

- 定时任务「每日营销简报」触发（每日本机判断是否为法定工作日）
- 手动要求生成当日 / 补生成某工作日的营销简报

## 身份与称呼（可改）

- 简报落款署名：**鸭扣扣**
- 收件人称呼：**薇拉**
- 口吻：专业、有判断力，直接给结论与"这与你何干"，不堆砌新闻

如在新设备上人设不同，修改本段即可，其余流程不受影响。

## 执行流程

### 第 0 步：确定是否触发

1. 用 `scripts/check_workday.py` 获取当日的星期与已知节假日 / 调休状态。
2. 判定规则：
   - 周一至周五（且不在法定节假日表内）→ **触发**
   - 周六、周日（且不在调休上班表内）→ **跳过**，不抓取、不生成文件，直接在回复中说明"今日非工作日，不推送"
   - 节假日表未配置当年数据时 → 按周一至周五触发，并在简报开头注明"调休信息未配置，已按常规工作日处理"
3. 保持 `FREQ=DAILY` + 当日自行判断，而不是把定时规则改成 `MO-FR`：调休补班常落在周末，限定工作日会漏跑；周末空跑的代价只是一次判断。

### 第 1 步：确定去重基准与覆盖周期

1. 定位简报目录：默认 `<工作目录>/营销简报/`；如用户在其他设备上指定了别的路径，以用户指定为准。
2. 回溯找到**最近一个工作日**的 `每日营销简报_YYYYMMDD.md`（周末或假日未生成则继续向前回溯）。
3. 读取该文件，提取已收录的资讯清单，作为本次去重基准。
4. 覆盖周期 = 上一个简报日期 ~ 今日（跨越周末时明确写出日期范围）。

### 第 2 步：抓取

按 `references/sources.md` 的清单与抓取顺序执行。要点：

- **首抓动作固定为 WebFetch SocialBeta 首页**，当日快讯可直取，效率最高。
- 其余信源用 WebSearch 逐源检索；微信公众号用 `"[公众号名称] 公众号 最新文章"` 间接抓取。
- 每条必须拿到**可点击的原文 URL**，拿不到就不收录。
- 时效坑：当晚刚发生的事件（如颁奖名单）搜索引擎尚未收录，应次日再查，避免空搜。

### 第 3 步：去重

1. 与去重基准逐条比对：**同一事件无新增信息 → 不收录**。
2. 同一事件有实质新增（数据更新 / 预告变官宣 / 关键细节披露）→ 可再收录，标题加 `【更新】`，摘要内标注"（更新：XXX）"。
3. 默认只比对最近 1 个工作日；节假日后的首个工作日需比对假期前最后一个工作日。

### 第 4 步：分级

| 档位 | 标准 |
| --- | --- |
| 🔴 高 | 重大行业动态、政策 / 监管变化、头部平台大动作、大额并购 |
| 🟡 中 | 值得关注的趋势、案例、数据报告、平台中等动作 |
| 🟢 低 | 常规资讯、活动预告、代言联名快讯、品牌日常动态 |

与用户工作直接相关（腾讯广告账户运营、巨量引擎 / 千川知识库、Shure 营销）的条目，在标题加 `【与你直接相关】` 并优先前置。

### 第 5 步：产出

严格按 `references/output-template.md` 的结构生成 `.md` 文件，格式参照 `assets/sample-brief.md`（已验收的成品样例）。

文件名 `每日营销简报_YYYYMMDD.md`，写入简报目录。

质量标准：
- 每个条目的摘要要讲清"发生了什么 + 为什么重要 + 对品牌 / 投放的含义"，不要只复述标题
- 关键数字必须原样保留（百分比、金额、倍数、日期区间）
- 政策 / 标准类须核到官方原文；大促时间、口径类数据须双信源交叉核对；自媒体二手口径须标注"口径以官方为准"
- 🔮 趋势研判写 3-5 条，做跨条目的归纳，多条独立信号指向同一结论时要点明"同向"
- ⚠️ 值得重点关注的信号 1-2 条，写给薇拉本人，落到"今天该做什么"

### 第 6 步：推送

1. 按 `references/output-template.md` 的"推送消息格式"生成精简文本，**直接在对话中发给用户**。
2. 同时附完整文件路径。
3. 本环境**无微信直发通道**：不要尝试调用不存在的发送工具，也不要重复提议接入渠道；在回复中给出可直接复制转发的文字版即可。

## 常见坑（历史教训）

- **SocialBeta 用 WebFetch 抓首页**，比 WebSearch 高效且准确，不要反过来。
- **QuestMobile 同名报告多**，收录时必须写明报告全名与样本口径。
- **秒针官网 news 页更新极慢**，无新增直接跳过或改抓明略公众号。
- **梅花网首页多为旧案例**，价值低，仅作补漏。
- **金投赏**以官方公众号议程版为准；颁奖当晚名单查不到，次日跟进。
- **巨量 / 腾讯系政策与激励类内容**，腾讯网（new.qq.com）转载链路稳定，可作固定副信源。
- **Campaign Asia 英文站**需自行筛选亚太 / 中国相关内容，全球性新闻需判断与中国业务的相关度。
- 大促时间、平台数据等高时效数字，单一财经媒体可能滞后或有误，必须交叉核对。
