# 信息源清单与抓取策略

## 抓取顺序（效率优先）

1. **WebFetch `https://socialbeta.com/` 首页** —— 固定首抓动作。当日快讯可直取，带时间戳与链接，效率最高。
2. **WebSearch 逐源检索**其余固定信源，检索式建议：`"站点或品牌名 + 主题关键词 + 日期"`，如 `巨量引擎 双11 激励 2026年10月21日`。
3. **微信公众号**无直接抓取通道，用 search_web 间接检索：`"[公众号名称] 公众号 最新文章"`。
4. 补漏阶段再扫补充信源（见 C 段）。

## 抓取纪律

1. **每条必须附可点击的原文 URL**，拿不到就不收录。
2. **双信源交叉核对**：政策、标准、大促时间、平台数据这类高时效或高敏感度信息，优先"官方发布原文 + 财经媒体转载"组合。
3. **标注口径**：自媒体二手解读标"口径以官方为准"；券商跟踪标"以财报 / 官方为准"。
4. **避免空搜**：事件当晚（如颁奖、发布会）搜索引擎尚未收录，改次日再查，不要在当期硬凑。
5. **覆盖度检查**：出稿前回看 13 个核心源是否都扫过；确实无新增的源可以一句话带过，但不要整段漏掉。
